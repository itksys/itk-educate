エンジニア職の方はもちろん、営業・管理部門の方も対象です。 お客様や開発メンバーと話すときの「共通言語」になる知識を、短いレッスンにまとめています。

レッスン一覧

課題あり！ が付いているレッスンでは、最後に成果物（作ったプロジェクト）を zip ファイルにまとめて提出します。

1

ITエンジニアは何を作る人？

Webアプリ・モバイルアプリ（iOS / Android）・組み込みアプリなど、作るものの種類と違いを学びます。所要時間 約15分。

 2

アプリが動くしくみ

OSI参照モデルを入り口に、URLを入力してから画面が表示されるまでの流れと、サーバー・データベース・クラウドの役割を学びます。所要時間 約25分。

 3

IT業界の職種

PM・SE・PG・デザイナー・フロントエンド・バックエンド・DB・インフラ・テスターなど、IT業界の職種と役割の違いを学びます。所要時間 約20分。

 4

開発の流れ

要件定義から設計・開発・テスト・リリース・運用まで、システム開発の工程と、ウォーターフォール・アジャイルなどの進め方を学びます。所要時間 約20分。

 5

HTMLとは？はじめての Hello World課題あり！

Webページの骨組みを作る HTML のしくみを学び、メモ帳とブラウザだけで Hello World! を表示します。所要時間 約20分。

 6

開発環境を整えよう

Chrome・VS Code・Claude Code をインストールして、プロと同じ道具をそろえます。所要時間 約30分。

 7

ポートフォリオを作ろう① HTML

自己紹介のポートフォリオサイトを作るシリーズ。まずは HTML で骨組みを作ります。所要時間 約30分。

 8

ポートフォリオを作ろう② CSS

CSS で色や配置を整えて、ポートフォリオの見た目をおしゃれにします。所要時間 約30分。

 9

ポートフォリオを作ろう③ JavaScript課題あり！

JavaScript でボタンを押すと動く仕掛けを付けて、ポートフォリオを完成させます。所要時間 約30分。

 10

ポートフォリオを TypeScript にしよう

JavaScript に「型」を足した TypeScript のしくみを学び、ポートフォリオのスクリプトを書き換えます。所要時間 約40分。

 11

言語・フレームワーク・ライブラリを整理しよう

HTML・CSS・JavaScript・TypeScript・Java などの言語と、Vue.js・React・Spring Boot などのフレームワーク、jQuery などのライブラリの関係を整理します。所要時間 約25分。

 12

ポートフォリオを Vue.js にしよう課題あり！

ポートフォリオを Vue.js（Vite ＋ Vue 3 ＋ TypeScript）の部品に分けて作り直します。所要時間 約60分。
