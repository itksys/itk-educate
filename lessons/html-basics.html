HTMLとは？
はじめての Hello World

ここからは、いよいよ実際に手を動かして作ってみます。 最初に学ぶのは、Webページの骨組みを作る言語「HTML」。 ゴールは、自分で書いたHTMLでブラウザに Hello World! を表示することです。

「プログラミングって、黒い画面に英語がずらーっと並ぶやつでしょ……？」と身構えた方。大丈夫です。 今日使う道具は、どのパソコンにも最初から入っている「メモ帳」とブラウザだけ。インストールも不要です。

所要時間は約20分。コーヒーが冷める前に、はじめての Webページが完成します。

2. HTML・CSS・JavaScript の役割分担

Webページは、役割の違う3つの言語でできています。このシリーズでも、この3つを順番に学んでいきます。

HTML

骨組み・中身を作る。「ここは見出し」「ここは文章」「ここに画像」と、ページの構造を決めます。

家でいうと 柱・壁・間取り

CSS

見た目を整える。色・文字の大きさ・配置・余白など、デザインを担当します。

家でいうと 壁紙・塗装・家具の配置

JavaScript

動きを付ける。ボタンを押したら何かが起きる、などの仕掛けを作ります。

家でいうと 照明のスイッチ・自動ドア

この3つは、Lesson 7〜9 のポートフォリオ作りで、HTML → CSS → JavaScript の順に1つずつ足していきます。今日はまず HTML です。

3. HTMLは「タグ」で意味を付ける

HTML は HyperText Markup Language の略です。「Markup（マークアップ）」とは、文章に目印を付けること。 HTMLでは、< と > で囲んだタグという目印で、文章の各部分が「何なのか」をブラウザに伝えます。

ポイント： HTMLは「見た目」ではなく「意味」を伝える言語です。<h1> は「大きな文字にして」ではなく「これは見出しです」という意味。 見た目を変えるのは、Lesson 8 で学ぶ CSS の役割です。

4. よく使うタグ

タグはたくさんありますが、最初はこれだけ知っていれば十分です。どれも Lesson 7 のポートフォリオで使います。

タグ意味書き方の例
h1〜h6見出し（数字が小さいほど大きな見出し）<h1>自己紹介</h1>
p段落（ひとまとまりの文章）<p>はじめまして。</p>
ul と li箇条書きのリスト<ul><li>りんご</li></ul>
img画像（終了タグがない）<img src="cat.jpg" alt="ねこ">
aリンク<a href="https://...">こちら</a>

src="cat.jpg" のように、タグの中に書く追加情報を属性（ぞくせい）と呼びます。 img なら「どの画像を表示するか（src）」「画像の説明（alt）」を属性で指定します。

5. HTMLページの基本の形

HTMLファイルは、いつも次のような「お決まりの形」で書きます。最初は意味を全部覚えなくて大丈夫。「こういう箱に入れるもの」と思ってください。

基本の形（← から右は説明なので、書かなくてOK）
<!DOCTYPE html>            ← 「これはHTMLです」という宣言
<html lang="ja">           ← ここからHTML（日本語のページ）
<head>                     ← ページの「設定」を書く場所（画面には出ない）
  <meta charset="UTF-8">   ← 文字コードの指定（文字化け防止）
  <title>タイトル</title>  ← ブラウザのタブに表示される名前
</head>
<body>                     ← ここに書いたものが画面に表示される
  ここに中身を書く
</body>
</html>                    ← HTMLの終わり

たとえるなら、<head> は荷物の送り状（中身ではないけれど大事な情報）、 <body> は箱の中身です。

6. やってみよう：Hello World!

プログラミングの世界では、はじめて書くプログラムで 「Hello World!」と表示するのが昔からのお約束です。 1970年代のプログラミング言語の入門書で使われたのが始まりと言われ、今では世界中のエンジニアが最初に通る「入学式」のようなもの。 さっそくやってみましょう。（ここでは Windows のメモ帳を使います）

  1. 作業用のフォルダを作る

    デスクトップで右クリック →「新規作成」→「フォルダー」を選び、名前を hello にします。

  2. メモ帳を開く

    スタートメニューで「メモ帳」と検索して開きます。

  3. 次のコードを入力する

    まずは1文字ずつ自分で打ってみるのがおすすめ。どうしても大変なら「コピー」ボタンを使ってもOKです。

    hello.html
    <!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>はじめてのHTML</title>
</head>
<body>
  <h1>Hello World!</h1>
  <p>これが私のはじめてのWebページです。</p>
</body>
</html>

  4. 「hello.html」という名前で保存する

    メニューの「ファイル」→「名前を付けて保存」を選び、先ほど作った hello フォルダに保存します。 このとき、次の3点に注意してください。

    • ファイル名：hello.html（最後を .html にする）
    • ファイルの種類：「すべてのファイル」を選ぶ（「テキスト文書」のままだと hello.html.txt になってしまう）
    • エンコード：「UTF-8」を選ぶ（文字化け防止）

  5. ダブルクリックで開く

    保存した hello.html をダブルクリックすると、ブラウザが開いて次のように表示されます。

hello.html

↑ 表示例（実物です）。ブラウザのタブには <title> に書いた「はじめてのHTML」が表示されます。

おめでとうございます！ これであなたも、HTMLで Webページを作ったことのある人の仲間入りです。 世界中のどんな大きな Webサイトも、根っこはこの数行と同じ仕組みでできています。

ちょっと改造してみよう

メモ帳に戻ってコードを書き換え、上書き保存（Ctrl + S）してから、ブラウザで再読み込み（F5）してみましょう。

  • Hello World! を自分の名前に変えてみる
  • <p> の行をコピーして、2行・3行と増やしてみる
  • <h1> を <h2> や <h3> に変えて、大きさの違いを見てみる

おまけ：他のサイトのHTMLものぞいてみよう

ブラウザで好きな Webページを開いて、Ctrl + U を押してみてください。 そのページの HTML（ソースコード）が表示されます。どんな大きなサイトも、<html> や <body> から始まっているのがわかるはずです。 もちろん、このページでも見られますよ。

7. うまくいかないときは

こんなときは原因と対処
ダブルクリックするとメモ帳が開くファイル名が hello.html.txt になっている可能性があります。エクスプローラーの「表示」→「表示」→「ファイル名拡張子」にチェックを入れて確認し、.txt を消してください。
日本語が「縺薙ｌ縺ｯ…」のように文字化けする保存時のエンコードが UTF-8 になっていない可能性があります。「名前を付けて保存」でエンコードを「UTF-8」にして保存し直してください。
タグがそのまま画面に表示される< や > が全角（＜＞）になっていないか確認してください。HTMLのタグは半角で書きます。
書き換えたのに表示が変わらないメモ帳で上書き保存したか、ブラウザで再読み込み（F5）したかを確認してください。

まとめ

  • HTMLは、Webページの骨組み・中身を作る言語。フロントエンドの PG が書く。
  • 見た目は CSS、動きは JavaScript が担当する。
  • HTMLはタグで文章に「見出し」「段落」などの意味を付ける。開始タグ＋内容＋終了タグ＝要素。
  • 画面に出る中身は <body>、ページの設定は <head> に書く。
  • メモ帳とブラウザだけでも、Webページは作れる！

課題：自分だけの Hello World ページを提出しよう課題あり！

このレッスンで作った hello.html を、自分用に改造して提出してください。

課題の内容

  • <h1> の中を、自分の名前にする（例：<h1>Hello! 山田太郎です</h1>）
  • <p> を2つ以上使って、かんたんな自己紹介を書く
  • <h2> を1つ以上使って、「好きなもの」などの小見出しを作る
  • <title> を、自分のページらしい名前に変える

提出前のチェックリスト

  • ダブルクリックするとブラウザで開き、日本語が文字化けせずに表示される
  • ファイル名が hello.html になっている（hello.html.txt になっていない）
  • <h1>・<h2>・<p> を使っている

提出のしかた

  1. 提出用のフォルダを作る

    デスクトップなどに、Lesson05_氏名 という名前のフォルダを作ります（例：Lesson05_YamadaTaro）。

  2. プロジェクトのフォルダをコピーして入れる

    Lesson 5 で作った hello フォルダを、まるごと提出用のフォルダにコピーします。

  3. zip ファイルにまとめる

    提出用のフォルダを右クリック →「圧縮先」→「ZIP ファイル」を選びます（Windows 10 の場合は「送る」→「圧縮（zip 形式）フォルダー」）。 同じ場所に Lesson05_氏名.zip ができます。

  4. 共有する

    できた zip ファイルを、講師・担当者から案内された共有先にアップロードして提出します。

提出する前に、zip ファイルをダブルクリックして中身を開き、必要なファイルがそろっているか確認しておくと安心です。
