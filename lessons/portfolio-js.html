2. JavaScriptの考え方

HTML が「骨組み」、CSS が「見た目」なら、JavaScript は「仕掛け」です。 JavaScript のプログラムは、ほとんどが次の形の組み合わせでできています。

JavaScript がページを書き換えるときは、まず「どの部分を書き換えるか」をHTMLの中から探し、次に中身を書き換えます。 そのため、HTML のタグに id や class という名札を付けておき、それを目印に探します。

4. ① 時間帯のあいさつ

script.js
// ① 時間帯に合わせて、あいさつを変える
const greeting = document.getElementById("greeting");
const hour = new Date().getHours();

if (hour < 10) {
  greeting.textContent = "おはようございます！";
} else if (hour < 18) {
  greeting.textContent = "こんにちは！";
} else {
  greeting.textContent = "こんばんは！";
}

1行ずつ、日本語に訳してみましょう。

コード日本語にすると
// …コメント（メモ書き）。プログラムとしては無視される
const greeting = document.getElementById("greeting");ページの中から、名札（id）が greeting の部分を探して、greeting という箱（変数）に入れておく
const hour = new Date().getHours();今の時刻の「時」（0〜23）を調べて、hour という箱に入れておく
if (hour < 10) { … }もし 10時より前なら、「おはようございます！」にする
else if (hour < 18) { … }そうではなく 18時より前なら、「こんにちは！」にする
else { … }どれでもなければ、「こんばんは！」にする
greeting.textContent = "…";greeting の部分の文字を書き換える
変数は「名前付きの箱」： const 名前 = 中身; と書くと、中身に名前を付けて取っておけます。何度も使うものに名前を付けておくと、プログラムが読みやすくなります。 if 〜 else は条件分岐といって、「場合によってやることを変える」ための書き方です。

5. ② 鉄棒アニメーション

あいさつの下に、空行を1行あけて続けて書きます。

script.js（続き）
// ② 鉄棒の人が、くるくる回り続ける
const person = document.getElementById("person");
const tetsubo = document.getElementById("tetsubo");
let angle = 0;
let moving = true;

setInterval(function () {
  if (moving) {
    angle = angle + 5;
    person.style.transform = "rotate(" + angle + "deg)";
  }
}, 30);

tetsubo.addEventListener("click", function () {
  moving = !moving;
});
コード日本語にすると
let angle = 0;今の角度を入れておく箱を、0度で用意する（let は、あとで中身を変えられる箱）
let moving = true;「今動いているか」を入れておく箱。true は「はい」、false は「いいえ」
setInterval(function () { … }, 30);30ミリ秒（0.03秒）ごとに、{ } の中をくり返し実行する
angle = angle + 5;角度を5度増やす
person.style.transform = "rotate(" + angle + "deg)";人の画像を、その角度だけ回転させる（例：rotate(45deg)）
tetsubo.addEventListener("click", …)鉄棒のイラストがクリックされたら、{ } の中を実行する
moving = !moving;! は「反対にする」。動いていれば止める、止まっていれば動かす
アニメーションの正体： 0.03秒ごとに5度ずつ回転させているだけです。パラパラ漫画と同じで、少しずつ変えた絵を素早く切り替えると、人間の目には「動いている」ように見えます。 30 や 5 の数字を変えると、回る速さが変わります。いろいろ試してみましょう。

6. ③ コントローラー

script.js（続き）
// ③ コントローラーのボタンが、ポチポチ光る
const padButtons = document.querySelectorAll(".pad-button");

setInterval(function () {
  const index = Math.floor(Math.random() * padButtons.length);
  const padButton = padButtons[index];
  padButton.classList.add("pressed");
  setTimeout(function () {
    padButton.classList.remove("pressed");
  }, 200);
}, 350);
コード日本語にすると
document.querySelectorAll(".pad-button")名札（class）が pad-button の部分を全部探す（4つのボタンが、0番〜3番の番号付きで手に入る）
setInterval(function () { … }, 350);0.35秒ごとに、{ } の中をくり返す
Math.random() * padButtons.length0 以上 4 未満の、でたらめな数（例：2.71…）を作る
Math.floor( … )小数点以下を切り捨てる（2.71… → 2）。これで 0〜3 のどれかになる
padButtons[index]4つのボタンのうち、index 番目を取り出す
classList.add("pressed")そのボタンに pressed の名札を付ける（CSS の指定で光る）
setTimeout(function () { … }, 200);0.2秒たったら1回だけ、{ } の中を実行する。ここで名札を外して、元の暗い色に戻す

setInterval は「〇秒ごとにくり返す」、setTimeout は「〇秒たったら1回だけ」。 「光らせる → 0.2秒後に消す」を、0.35秒ごとにランダムなボタンでくり返すことで、だれかがポチポチ押しているように見えます。

プログラムの世界では、番号を 0 から数えるのが一般的です。最初は戸惑いますが、すぐに慣れます。

9. 動かないときは「コンソール」を見る

JavaScript は、1文字のミスでもまったく動かなくなることがあります。そんなときは、Chrome で F12 を押し、 デベロッパーツールの「コンソール（Console）」タブを開いてみましょう。エラーがあれば、赤い文字で原因と場所（ファイル名と行番号）が表示されます。

よくあるミス確認すること
何も動かない、どのボタンも反応しない<script src="script.js"> のファイル名が合っているか。script.js が同じフォルダにあるか。
Cannot read properties of null と出るHTML の id や class の名前と、JavaScript で探している名前が一致しているか（person と persan など）。

  • setInterval の数字を変えて、逆上がりやボタンの速さを変えてみる

まとめ

  • JavaScript は「きっかけ → やること」の組み合わせで動きを作る。
  • getElementById・querySelectorAll で、HTML の中から書き換えたい部分を名札（id / class）を目印に探す。
  • 変数（const / let）は名前付きの箱、if 〜 else は条件分岐、配列は番号付きのリスト。
  • addEventListener("click", …) で「クリックされたら」、setInterval で「〇秒ごとに」の処理を書く。
  • アニメーションは、少しずつ変えた状態を素早く切り替えるパラパラ漫画。
  • 動かないときは F12 →「コンソール」で赤いエラーを確認する。

HTML で骨組みを作り、CSS で見た目を整え、JavaScript で動きを付ける。 これは、世界中の Webサイトが作られているのとまったく同じ流れです。今日作ったポートフォリオは、その立派な第一歩です。
