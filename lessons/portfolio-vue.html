LESSON 12

ポートフォリオを
Vue.js にしよう

Lesson 10 で TypeScript にしたポートフォリオを、Lesson 11 で学んだフレームワークの1つ、 Vue.js（ビュー・ジェイエス）で作り直します。 最後には、現場と同じ形のプロジェクトで動かすところまで進みます。

ここまでのポートフォリオは、いわば手作りの一軒家。柱を立てて、壁を貼って、配線もぜんぶ自分でやってきました。 今回はハウスメーカーの工法を使って建て直します。「え、3回目の建て直し……？」という声が聞こえてきそうですが、 今回がいちばん「プロの現場っぽさ」を味わえる回です。

Lesson 11 のおさらい： フレームワークは「作り方の型」と便利な機能のセット。決まった型の中に、自分のコードを書き込んでいきます。 Vue.js は、HTML に近い書き方で学びやすい、画面（フロントエンド）のフレームワークです。

1. Vue.js の考え方

考え方①：データを変えると、画面が勝手に変わる

Lesson 9・10 では、画面を変えたいとき「HTML の中から探して（getElementById）、書き換える（textContent）」という2段階の作業をしていました。 Vue では、データ（箱の中身）を変えるだけで、そのデータを表示している画面が自動で書き換わります。これをリアクティブと呼びます。

Lesson 10：探して、書き換える
const message = document.getElementById("message") as HTMLElement;

// 画面のどこを変えるか探してから、文字を書き換える
message.textContent = "スーの歌も好きだよ";
→
Lesson 12（Vue）：データを変えるだけ
const message = ref<string>("下のボタンを押してみてね。");

// データを変えるだけ。画面は Vue が書き換えてくれる
message.value = "スーの歌も好きだよ";

<!-- 画面（HTML）側には「ここに message を表示」と書いておく -->
<p>{{ message }}</p>

たとえるなら、Lesson 10 は「掲示板の前まで歩いて行って、紙を貼り替える」やり方。Vue は「デジタルサイネージ」で、元のデータを変えれば、表示はすべて自動で切り替わります。

考え方②：画面を部品（コンポーネント）に分けて作る

Vue では、画面をコンポーネントという部品に分けて作ります。1つの部品は、1つの .vue ファイルに、 その部品の動き（script）と見た目（template）をセットで書きます。今回のポートフォリオは、こんな部品に分けます。

2. Vue のプロジェクトを作る

Vue のアプリは、Vite（ヴィート）という開発用ツールと組み合わせて作るのが標準です。Vite は、書いたコードをすぐにブラウザで確認できるようにしたり、 公開用のファイルにまとめたりしてくれます。準備には Lesson 10 で入れた Node.js を使います。

4. 部品（コンポーネント）に分けて書く

.vue ファイルは、上が <script setup lang="ts">（動き・TypeScript）、 下が <template>（見た目・HTML）という2つのパートでできています。1つずつ作っていきましょう。 src の中に components フォルダと utils フォルダを作っておきます。

部品0：ランダムに番号を選ぶ関数（utils/pickRandomIndex.ts）

Lesson 10 で作った関数を、別のファイルに切り出します。export を付けると、他のファイルから import して使えるようになります。

src/utils/pickRandomIndex.ts
// 0〜(length - 1) のどれかの番号を、ランダムに選ぶ
export function pickRandomIndex(length: number): number {
  return Math.floor(Math.random() * length)
}

Vue のプロジェクトでは、行の最後の ; を省略する書き方が一般的です（付けても動きます）。

部品1：カードの枠（components/ProfileCard.vue）

3つのカードに共通の「枠」を、使い回せる部品にします。

src/components/ProfileCard.vue
<script setup lang="ts">
// 親（App.vue）から受け取るデータ
defineProps<{
  title: string
  text?: string
}>()
</script>

<template>
  <section class="card">
    <h2>{{ title }}</h2>
    <p v-if="text">{{ text }}</p>
    <slot></slot>
  </section>
</template>
書き方意味
defineProps<{ title: string; text?: string }>()この部品を使う側から受け取るデータ（props）。title は文字で必須、text は ? が付いているので省略してもよい
{{ title }}受け取った title を、ここに表示する
v-if="text"text があるときだけ、この <p> を表示する
<slot></slot>使う側が中に入れたもの（鉄棒やコントローラーの部品）を、ここに差し込む

props は「注文票」、slot は「お弁当箱の空いたスペース」のイメージです。枠は同じでも、注文票と中身を変えれば別のお弁当になります。

部品2：鉄棒アニメーション（components/TetsuboAnimation.vue）

src/components/TetsuboAnimation.vue
<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue'

// ② 鉄棒の人が、くるくる回り続ける
const angle = ref<number>(0)
const moving = ref<boolean>(true)
let timer: number = 0

onMounted(function (): void {
  timer = window.setInterval(function (): void {
    if (moving.value) {
      angle.value = angle.value + 5
    }
  }, 30)
})

onUnmounted(function (): void {
  window.clearInterval(timer)
})

function toggle(): void {
  moving.value = !moving.value
}
</script>

<template>
  <div class="stage" id="tetsubo" @click="toggle">
    <img src="../assets/images/tetsubo-bar.svg" alt="鉄棒のイラスト">
    <img
      src="../assets/images/person.svg"
      alt=""
      class="person"
      :style="{ transform: 'rotate(' + angle + 'deg)' }"
    >
  </div>
  <p class="hint">イラストをクリックすると、止まったり動いたりします。</p>
</template>
書き方意味
import { ref, onMounted, onUnmounted } from 'vue'Vue の機能のうち、使うものを読み込む
const angle = ref<number>(0)画面と連動する箱を作る（中身は数字で、最初は 0）。script の中では angle.value で中身を読み書きする
onMounted( … )この部品が画面に表示されたときに実行する。ここでアニメーションを始める
onUnmounted( … )この部品が画面から消えるときに実行する。ここでアニメーションを止めて後片付けをする
@click="toggle"クリックされたら toggle 関数を実行する（Lesson 9 の addEventListener("click", …) と同じ）
:style="{ transform: 'rotate(' + angle + 'deg)' }"angle の値を使って、回転のスタイルを付ける。angle が変わると、自動で回転も変わる
ポイント： Lesson 10 では person.style.transform = … と、画面を直接書き換えていました。Vue 版のタイマーは angle.value を5増やしているだけ。 画面の書き換えは Vue が引き受けてくれています。これが「1章の考え方①」のリアクティブです。 なお template の中では .value を付けずに angle と書けます。

部品3：コントローラー（components/GameController.vue）

src/components/GameController.vue
<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue'
import { pickRandomIndex } from '../utils/pickRandomIndex'

// ③ コントローラーのボタンが、ポチポチ光る
const colors: string[] = ['red', 'yellow', 'green', 'blue']
const pressedIndex = ref<number>(-1) // 光っているボタンの番号（-1 はどれも光っていない）
let timer: number = 0

onMounted(function (): void {
  timer = window.setInterval(function (): void {
    pressedIndex.value = pickRandomIndex(colors.length)
    window.setTimeout(function (): void {
      pressedIndex.value = -1
    }, 200)
  }, 350)
})

onUnmounted(function (): void {
  window.clearInterval(timer)
})
</script>

<template>
  <div class="stage">
    <img src="../assets/images/game-base.svg" alt="ゲームのコントローラーのイラスト">
    <span
      v-for="(color, index) in colors"
      :key="color"
      class="pad-button"
      :class="[color, { pressed: index === pressedIndex }]"
    ></span>
  </div>
</template>
書き方意味
const pressedIndex = ref<number>(-1)今光っているボタンの番号を入れる箱。-1 は「どれも光っていない」
v-for="(color, index) in colors"colors のリストの数（4つ）だけ、<span> をくり返し作る。HTML にボタンを4回書かなくてよい
:key="color"くり返し作る1つ1つに付ける、見分けるための名前（v-for とセットで書くお約束）
:class="[color, { pressed: index === pressedIndex }]"色の名札（red など）を付け、さらに「自分の番号が pressedIndex と同じなら pressed の名札も付ける」

Lesson 10 では classList.add("pressed") → classList.remove("pressed") と、名札を手で付け外ししていました。 Vue 版は pressedIndex の番号を変えるだけで、どのボタンに名札を付けるかは Vue が判断してくれます。

部品4：ひとこと（components/RandomMessage.vue）

src/components/RandomMessage.vue
<script setup lang="ts">
import { ref } from 'vue'
import { pickRandomIndex } from '../utils/pickRandomIndex'

// ④ ボタンを押すと、ひとことがランダムに変わる
const messages: string[] = [
  '最近はエアロピクルスも好きだよ',
  'スーの歌も好きだよ',
  'ねずみなんだけど丑年なんでスー'
]
const message = ref<string>('下のボタンを押してみてね。')

function showMessage(): void {
  const picked = messages[pickRandomIndex(messages.length)]
  if (picked) {
    message.value = picked
  }
}
</script>

<template>
  <p id="message">{{ message }}</p>
  <button id="message-button" @click="showMessage">ひとことを見る</button>
</template>

if (picked) { … } は、Lesson 10 で出てきた「見つからないかもしれない」への備えです。 Vue のプロジェクトは TypeScript の設定が少し厳しめで、「リストから取り出したものは、ないかもしれないよ（undefined）」と教えてくれるので、 あるときだけ表示を変えるようにしています。

部品を組み立てる（App.vue）

最後に、いちばん外側の App.vue を書き換えて、部品を組み立てます。あいさつ（①）もここに書きます。

src/App.vue
<script setup lang="ts">
import ProfileCard from './components/ProfileCard.vue'
import TetsuboAnimation from './components/TetsuboAnimation.vue'
import GameController from './components/GameController.vue'
import RandomMessage from './components/RandomMessage.vue'

// ① 時間帯に合わせて、あいさつを変える
function getGreeting(hour: number): string {
  if (hour < 10) {
    return 'おはようございます！'
  } else if (hour < 18) {
    return 'こんにちは！'
  } else {
    return 'こんばんは！'
  }
}

const greeting: string = getGreeting(new Date().getHours())
</script>

<template>
  <header>
    <p id="greeting">{{ greeting }}</p>
    <h1>Mayu Takahashi Portfolio</h1>
    <p>はじめまして！ 私の好きなものを紹介します。</p>
  </header>

  <main>
    <ProfileCard title="特技：鉄棒" text="子どものころから鉄棒が大好きです。">
      <TetsuboAnimation />
    </ProfileCard>

    <ProfileCard
      title="今いちばんハマっているもの：Valorant"
      text="5人対5人で戦う、チーム対戦型のシューティングゲームです。"
    >
      <GameController />
    </ProfileCard>

    <ProfileCard title="ひとこと">
      <RandomMessage />
    </ProfileCard>
  </main>

  <footer>
    <p>&copy; 2026 Mayu Takahashi</p>
  </footer>
</template>
  • import ProfileCard from './components/ProfileCard.vue'：作った部品を読み込む
  • <ProfileCard title="…" text="…">：読み込んだ部品は、自分で作ったタグのように使える。title・text が props（注文票）
  • <TetsuboAnimation />：中身のない部品は、/> で閉じて1行で書ける。カードの <slot> の場所に入る
  • {{ greeting }}：あいさつの文字を表示する。HTML を探して書き換える必要はもうありません

5. 動かしてみる・公開用にまとめる

開発中：npm run dev

npm run dev を実行したままにしておくと、ファイルを保存した瞬間にブラウザの表示が自動で更新されます（いちいち F5 を押す必要がありません）。 下のように、Lesson 10 と同じ見た目・同じ動きになれば成功です。

localhost:5173（Vue.js 版）

↑ Vue.js 版の完成見本です。見た目も動きも Lesson 10 と同じですが、中身はまったく別の作りになっています。

公開するとき：npm run build

Web サイトとして公開するときは、次のコマンドで公開用のファイルにまとめます。

ターミナル
npm run build

型のチェック（Lesson 10 の tsc の役割）をしたうえで、dist フォルダに、ブラウザが読める HTML・CSS・JavaScript がまとめて作られます。 この dist フォルダの中身をサーバーに置けば公開完了です。 npm run preview を実行すると、まとめたファイルを公開前に確認できます。

このサイトの見本では、vite.config.ts に base: './' の1行を足して、どのフォルダに置いても動くようにしています。 なお、dist/index.html をダブルクリックで開いても表示されません。npm run preview や Web サーバーを通して開く必要があります。

まとめ

  • Vue.js はリアクティブ：ref の中身（データ）を変えるだけで、画面が自動で書き換わる。
  • 画面はコンポーネント（.vue ファイル）に分けて作る。1つのファイルに script（動き）と template（見た目）をセットで書く。
  • template では {{ }}（表示）・@click（クリック）・:style / :class（スタイル・名札）・v-for（くり返し）・v-if（条件）を使う。
  • 部品には props（注文票）でデータを渡し、slot で中身を差し込める。
  • プロジェクトは npm create vue@latest で作り、開発中は npm run dev、公開するときは npm run build。

HTML・CSS・JavaScript・TypeScript、そしてフレームワーク。Lesson 5 の「Hello World!」から、ついに現場と同じ道具立てまでたどり着きました。 ここまで来れば、実際のプロジェクトのコードを見ても「あ、これは部品だな」「ここでデータを変えているな」と読み解けるはずです。
